# 手工验收清单

适用于本地演示版本。所有操作发生在虚构店铺数据中。此清单记录预期检查项；实际运行结果由当前交付时的浏览器演示确认。

1. 使用 `operator / operator123` 登录，首页显示操作台与任务记录。
2. 输入“查待发货订单”，确认任务结果包含订单行和浏览器截图。
3. 输入“导出待发货订单”，确认有 CSV 下载链接，文件可正常打开。
4. 输入“查云感降噪耳机 Pro 库存”，确认匹配 SKU1001。
5. 输入“把云感降噪耳机 Pro 的库存改成 60 件”，确认先展示 SKU、旧值和新值；点击确认后结果显示操作步骤和截图。
6. 输入“将桌面机械键盘 Air 售价调到 279 元”，确认先预览价格差异，再确认完成。
7. 输入“给订单 DD20261021002 发货，运单号 SF12345678”，确认订单、运单号后执行；模拟后台状态应改为已发货。
8. 输入“查询待审核售后记录”，确认能看到 AS1001；不应出现批准或退款动作。
9. 检查操作截图、任务记录和 CSV 文件位于 `data/operations/`。

## 环境检查

- `node --check web/app.js`
- `node --check web/mock-admin.js`
- `.venv/Scripts/python.exe -m compileall -q app`
